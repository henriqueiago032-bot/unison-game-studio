QUEM SOMOS

UMA IDEIA. INÚMEROS UNIVERSOS.

A UNISON GAME STUDIO é uma marca independente criada por Iago Henrique para desenvolver, reunir e publicar os jogos que nascem de suas próprias ideias.

Este projeto representa o começo de uma jornada criativa: construir personagens, histórias e mundos originais, evoluindo um jogo de cada vez.

UNISON — Criando mundos, juntos.
